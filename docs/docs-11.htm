#Recommended Practices

- **Routine monitoring:** Review Battery Health and Full Charge Capacity periodically.
- **Discharge monitoring:** Observe Current Capacity, Power State, and Charging/Discharging Rate.
- **Technical troubleshooting:** Use R.A.W. Value when you need to inspect device communication results.
- **Long-term comparison:** Keep periodic records if you want to track capacity changes over time.
- **Unexpected shutdowns:** Do not rely on Battery Health alone. A battery can report a relatively high capacity while still experiencing other problems.

Do not deliberately force the battery into deep discharge simply to test the software, especially if the laptop already exhibits unexpected shutdowns.
