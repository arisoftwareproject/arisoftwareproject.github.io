#Select Battery Slot

The **Select Battery Slot** dropdown allows users to select an available battery interface detected by the software.

Example:

`#1 AL12A32 (SANYO)`

This entry identifies the first detected battery interface, with the reported device name AL12A32 and manufacturer SANYO.

The slot number represents the enumeration order of the detected interface. It does not indicate battery health or quality.

If multiple battery interfaces are available, users can select another entry to inspect its reported information.
