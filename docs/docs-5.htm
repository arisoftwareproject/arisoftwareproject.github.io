#Charging/Discharging Rate

The **Charging/Discharging Rate** field displays the reported battery power rate in milliwatts (mW).

Example:

`-6186 mW`

If the software uses negative values to represent battery discharge, this corresponds to approximately 6.186 watts of power leaving the battery.

Depending on the software's sign convention:

- A negative value may indicate discharging.
- A positive value may indicate charging.
- A zero value may indicate no reported power flow or an unchanged reading.

The interpretation of the sign depends on the software's implementation and the source data.

The rate can fluctuate as CPU activity, display brightness, storage activity, wireless networking, and other system loads change.

This value represents power, not battery capacity or voltage.
